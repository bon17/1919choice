# 1919년, 당신이라면 무엇을 요구하시겠습니까?

중학교 2학년을 위한 역사 조사 게임. 현재는 여성 노동자 한 명을 만나는 프로토타입입니다.

## 실행

Python 3와 Node.js 18 이상이 필요합니다. 외부 패키지 설치는 필요 없습니다.

```sh
npm run dev
```

브라우저에서 실행한 서버의 5173 포트에 접속합니다. 클라우드에서는 사용하는 플랫폼의 포트 미리보기 기능을 이용합니다.

## 검증

```sh
npm test
```

개발 환경에 Python Playwright와 `/usr/bin/chromium`이 있으면, 서버 실행 중 `python3 tests/browser_smoke.py`로 실제 브라우저 흐름도 확인할 수 있습니다. 이 검증 도구들은 앱 실행에 필요하지 않습니다.

질문 3개 → 요구와 발언 근거 연결 → 인물 반응 → 변화 지도 기록 흐름입니다. 같은 브라우저에서 진행을 저장하고 이어갈 수 있습니다. 다시하기는 확인 후 이 게임 기록만 초기화합니다.

현재 한 장면만 구현했습니다. 나머지 인물, 제도 비교, 정책 제안, 최종 변화안은 후속 구현 범위입니다. 인물과 발언은 학습용 재구성이며 최종 역사 콘텐츠 검토는 출시 전에 필요합니다.

기획: [PRD](docs/PRD.md) · [다이어그램](docs/DIAGRAMS.md)

## 서버 없이 바로 체험

`play.html` 파일을 내려받아 브라우저에서 열면 됩니다. 배포하는 `index.html`도 CSS와 JavaScript를 포함한 단일 파일이며, 외부 파일을 따로 받지 않습니다. `editions/`에는 내용으로 구분한 고유 버전을 보관하므로 이전 링크는 그 버전을 그대로 보여줍니다. 재생성은 `python3 scripts/build-standalone.py`로 합니다. 화면 틀은 `shell.html`, 실제 콘텐츠와 동작은 `app.js`·`game.js`, 스타일은 `style.css`에서 수정하고 다시 생성합니다.

## GitHub Pages 배포

GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다. 배포가 완료되면 이 화면에 실제 사이트 주소가 표시됩니다. 이 설정은 GitHub 권한이 있는 사용자가 한 번 적용해야 합니다.

배포 검증은 공개 사이트를 실제 Chromium 브라우저로 플레이합니다. 배경 설명과 인물의 답변, 진행 복원까지 확인하고 화면 캡처를 GitHub Actions 결과에 보관합니다.
