# 1919년, 당신이라면 무엇을 요구하시겠습니까?

중학교 2학년을 위한 역사 조사 게임입니다. 일곱 사람의 목소리를 여섯 장면에서 만나고, 정치적 권리와 경제적 삶을 함께 다루는 변화안을 만듭니다.

[공개 게임](https://bon17.github.io/1919choice/) · [PRD](docs/PRD.md) · [내용·출처](docs/CONTENT_PLAN.md) · [다이어그램](docs/DIAGRAMS.md) · [수정사항 반영표](docs/REVISION_CHECKLIST.md)

## 구현한 활동

| 장면 | 활동 |
| --- | --- |
| 여성 노동자 | 세 이야기에서 직접 단서 찾기 → 주목한 요구와 발언 근거 연결 |
| 팽크허스트 | 인물 소개 → 1913·1914·1918·1928년 자료를 하나씩 읽기 → 권리·행동·변화를 한 화면 하나씩 연결 |
| 두 시민 | 선거 참여 범위와 이유 비교 → 바이마르 헌법 → 두 목소리 기록 |
| 러시아 농민 | 별도 러시아 게임의 토지 요구를 짧게 회상 |
| 공장 노동자 | 생활·소유·운영·분배에 관한 이야기 → 정책과 근거 → 사회주의의 뜻과 확산 |
| 젊은 노동자 | 모은 카드로 정치·경제 제안과 각각의 근거를 연결 |
| 핵심 발견·엔딩 | 두 요구의 동시 가능성 → 완성 지도 → 수업 토론 |

점수·감점·강제 타이머 없이 진행합니다. 본편 17분과 다시 읽기·수정 여유 3분을 위한 분량 설계이며 실제 학생의 플레이 시간은 수업에서 확인해야 합니다.

첫 인물은 일자리·생활 지원·정치 참여 모두 타당한 근거와 연결되면 기록합니다. 모든 선택을 참정권으로 바꾸지 않습니다. 공장 노동자에게는 생활 지원의 도움을 인정하면서 소유·운영·분배의 요구도 설명합니다. 마지막 변화안은 여러 타당한 조합을 허용합니다.

지도에는 7개의 고유 목소리가 기록됩니다. 젊은 노동자 카드는 두 영역에 표시되지만 목소리 수는 한 번만 셉니다. 카드를 펼쳐 요구·근거·제안을 다시 볼 수 있습니다. 완료한 장면은 다시 살펴보고 수정할 수 있으며 새 제출이 확인되기 전까지 기존 카드는 보존합니다.

같은 브라우저에서 이어하기·새로고침 복원·확인 후 초기화를 지원합니다. 예전 한 장면 체험판과 v3 전체 게임의 기록은 첫 인물의 선택을 유지하며 전체 게임으로 옮깁니다. 저장이 차단되면 현재 탭에서 계속할 수 있습니다. 러시아 게임의 계정·완료 기록은 필요하지 않습니다.

모든 장면은 배경 → 이야기·단서 → 내 생각 → 목소리 기록으로 나뉩니다. 이야기 버튼만 누르면 진행되지 않고 발언의 단서를 직접 골라야 합니다. 그림은 전체 구도를 유지하고 화자와 함께 바뀝니다. 효과음은 기본 꺼짐이며 동작 줄이기 설정을 지원합니다.

## 실행과 빌드

Python 3와 Node.js 18 이상이 필요하며 앱 실행에 외부 패키지 설치는 필요 없습니다.

```sh
npm run dev
```

내부 확인은 실행한 서버의 5173 포트를 사용합니다. 사용자에게는 공개 게임 주소를 제공합니다.

```sh
python3 scripts/build-standalone.py
```

화면 틀은 `shell.html`, 콘텐츠·규칙은 `game.js`, UI는 `app.js`, 스타일은 `style.css`입니다. `assets/woman-worker.webp`와 `assets/cast-sheet.webp`는 역사 사진이 아닌 수업용 재구성 삽화입니다.

빌드는 CSS·JavaScript·삽화를 모두 포함한 `index.html`과 `play.html`을 생성합니다. 별도 이미지 요청 없이 사용할 수 있습니다. `editions/`의 내용으로 구분한 버전은 이전 링크의 내용을 보존합니다. `play.html`을 내려받아 사용할 수도 있습니다.

## 검증

```sh
npm test
```

게임 규칙 테스트는 자료 청취 조건, 여러 허용 조합, 부분 충족 반응, 목소리 중복 방지, 이동 조건, 저장 복원과 이전 체험판 기록 이전을 확인합니다.

Python Playwright와 Chromium이 있는 개발 환경에서는 서버를 실행하고 다음을 확인합니다. 이 도구는 앱 실행의 필수 의존성이 아닙니다.

```sh
TEST_BASE_URL=http://127.0.0.1:5173 python3 tests/browser_smoke.py
```

브라우저 테스트는 PC와 휴대폰 크기에서 모든 장면을 직접 조작해 엔딩까지 진행합니다. 이미지, 정책 대안, 누적 지도, 새로고침, 이전 기록, 저장 차단, 모바일 가로 넘침과 초기화를 확인하고 화면을 저장합니다.

## 배포

현재 저장소의 GitHub Pages는 `main`의 루트에서 배포하도록 설정되어 있습니다. `.github/workflows/pages.yml`은 푸시 후 공개 HTML이 생성한 파일과 정확히 같은지 비교하고 공개 사이트에서 전체 브라우저 플레이를 검증합니다. 검증 화면은 Actions의 `public-game-screenshots`에 보관합니다.

인물 대사·정책 비교안·삽화는 수업용 재구성입니다. 동아 역사1 교과서의 자료와 시점을 설명에 구분했습니다. 실제 수업 전에 교사가 분량과 역사 표현을 검토할 수 있도록 출처와 토론 질문을 함께 제공합니다.
