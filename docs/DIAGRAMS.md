# 웹앱 이해를 위한 다이어그램

이 웹앱에서 학생은 7명의 이야기를 듣고 요구를 수집합니다. 정답을 맞혀 점수를 얻는 대신, 사람들이 원하는 변화를 두 영역의 지도에 모읍니다.

## 1. 학생이 보게 되는 화면 흐름

```mermaid
flowchart TD
    A[시작 또는 이어하기] --> B[인물의 배경과 첫 이야기]
    B --> C[궁금한 질문 선택]
    C --> D[새 발언을 조사 노트에 수집]
    D --> R{세 이야기를 모두 들었는가?}
    R -- 아니요 --> C
    R -- 예 --> E[요구와 근거 또는 제안을 인물에게 확인]
    E --> F{인물의 생각과 연결되는가?}
    F -- 근거 부족 --> C
    F -- 발언 연결 확인 --> G[인물이 설명한 이유를 듣고 해석 보완]
    G --> E
    F -- 부분 충족 --> H[그것도 중요하지만 더 바라는 변화가 있다는 답변]
    H --> E
    F -- 생각 확인 --> I[개념 연결과 변화 지도 기록]
    I --> J{7번째 인물인가?}
    J -- 아니요 --> B
    J -- 예 --> K[핵심 발견과 엔딩]
    K --> L[완성 지도와 수업 토론]
```

질문에는 정답이 없습니다. 첫 인물의 세 이야기를 모두 들으면 정리 버튼이 활성화됩니다. 학생이 버튼을 누르기 전까지는 마지막 답변을 계속 읽을 수 있습니다. 학생이 대화를 통해 단서를 얻고, 자신의 판단을 발언으로 뒷받침합니다. 처음 두 명은 조사 방법을 익히고, 다음 두 명은 제도를 비교하고, 그다음 두 명은 정책을 제안합니다. 마지막에는 두 요구를 함께 다루는 변화안을 만듭니다.

## 2. 7명의 목소리가 만드는 변화 지도

```mermaid
flowchart LR
    A[1 여성 노동자: 여성 참정권] --> P[정치 참여 확대]
    B[2 팽크허스트: 여성 참정권 운동] --> P
    C[3 평범한 시민: 보통 선거] --> P
    D[4 독일 시민: 공화정 확대] --> P
    E[5 공장 노동자: 생활 개선] --> Q[경제적 평등 요구]
    F[6 러시아 농민: 토지 문제] --> Q
    G[7 젊은 노동자: 투표권과 생활 개선] --> P
    G --> Q
    P --> R[민주주의의 확산]
    Q --> S[사회주의의 확산]
    R --> T[정치적 권리와 더 나은 경제적 삶을 함께 요구할 수 있다]
    S --> T
```

첫 정치 참여 카드를 얻으면 ‘민주주의의 확산’이 공개되고, 첫 경제적 평등 카드를 얻으면 ‘사회주의의 확산’이 공개됩니다. 마지막 인물의 카드는 양쪽에 연결되지만 수집한 인물 수는 한 명으로 계산합니다. 경제적 요구를 했다는 사실만으로 모든 인물이 사회주의자였다고 단정하지 않습니다.

## 3. 플레이 화면의 구성

```mermaid
flowchart TB
    subgraph Screen[인물 플레이 화면]
        A[상단: 조사단 제목과 진행도 3/7]
        B[인물 영역: 이름·생활과 제약의 배경·발언]
        C[활동 영역: 질문·요구와 근거·제도와 정책 카드]
        D[피드백 영역: 인물 반응·수정 안내·개념 연결]
        E[이동 버튼: 다음 목소리 듣기]
        subgraph Map[변화 지도]
            F[정치 참여: 수집 카드와 민주주의 개념]
            G[경제적 평등: 수집 카드와 사회주의 개념]
        end
    end
    A --> B --> C --> D --> E
    D -. 조사 완료 시 카드 기록 .-> F
    D -. 조사 완료 시 카드 기록 .-> G
```

PC에서는 지도와 이야기를 함께 볼 수 있습니다. 모바일에서는 지도 버튼으로 펼쳐 확인합니다. 다음 버튼은 조사 과제를 완료하고 인물의 반응을 읽은 뒤 사용할 수 있습니다.

## 4. 기능 구성

```mermaid
flowchart TD
    A[역사 학습 웹앱] --> B[이야기 탐색]
    A --> C[선택과 학습 피드백]
    A --> D[변화 지도]
    A --> E[학습 정리]
    A --> F[진행 관리]
    B --> B1[질문 선택과 단서 수집]
    C --> C1[요구와 근거 연결·제도 비교·정책 제안]
    C --> C2[인물의 인정·추가 설명을 듣고 생각 보완]
    C --> C3[최종 변화안과 개념 연결]
    D --> D1[요구 카드 수집]
    D --> D2[카드별 발언 다시 보기]
    E --> E1[두 요구의 동시 가능성 발견]
    E --> E2[엔딩과 교사 토론 질문]
    F --> F1[같은 브라우저에서 이어하기]
    F --> F2[확인 후 다시하기]
```

회원가입이나 성적표 없이 수업에서 바로 시작하는 구성이며, 교사는 마지막 질문을 활용해 학생의 이해를 확인합니다.

## 5. 마지막 변화안을 만드는 방식

```mermaid
flowchart LR
    A[젊은 노동자 인터뷰] --> B[투표할 권리를 원한다는 발언]
    A --> C[너무 가난하게 살지 않기를 바라는 발언]
    B --> D[정치적 요구와 근거 연결]
    C --> E[경제적 요구와 근거 연결]
    D --> F[정치 참여 확대 제안]
    E --> G[노동자 생활 개선 제안]
    F --> H[두 제안을 담은 변화안]
    G --> H
    H --> I[두 요구를 함께 할 수 있다는 발견]
```

한쪽만 제안하면 인물이 아직 다뤄지지 않은 요구를 이야기합니다. 두 요구와 각각의 근거·제안이 연결되면 완료됩니다. 하나의 정해진 정책 조합만 강요하지 않고, 근거에 맞는 타당한 조합을 허용합니다.

진행 기록에는 들은 질문, 모은 발언, 선택 중인 카드와 조사 완료 상태가 포함됩니다. 같은 브라우저에서는 새로고침 후 이어갈 수 있고, 저장이 차단되면 현재 탭에서 계속할 수 있습니다.

## 6. 엔딩에서 정리할 역사 흐름

```mermaid
flowchart TD
    A[제1차 세계 대전] --> B[전쟁 피해·물가 상승·식량 부족·사회 변화]
    B --> C[예전 세상으로 그대로 돌아갈 수 없다]
    C --> D[나도 정치에 참여하고 싶다]
    C --> E[더 평등하게 살고 싶다]
    D --> F[여성 참정권·보통 선거·공화정 확대]
    E --> G[노동자 생활·토지 문제]
    H[1917년 러시아 혁명: 선행 사건] --> I[사회주의 확산의 배경]
    F --> J[민주주의의 확산]
    G --> I
    J --> K[두 요구는 함께 존재할 수 있다]
    I --> K
    K --> L[토론: 노동자라면 반드시 하나만 선택해야 했을까?]
```

공화정이 언제나 민주주의를 보장하는 것은 아니며, 나라별 변화의 시기와 범위도 다릅니다. 게임에서는 대표적인 사례를 통해 두 학습 축을 이해하게 합니다.
