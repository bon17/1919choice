# 웹앱 이해를 위한 다이어그램

학생은 구현된 여섯 장면에서 일곱 사람의 이야기를 듣고 요구를 수집합니다. 정답을 맞혀 점수를 얻는 대신, 사람들이 원하는 변화를 두 영역의 지도에 모읍니다.

## 1. 확정한 전체 화면 흐름

```mermaid
flowchart TD
    A[시작 또는 이어하기] --> B[여성 노동자: 배경 화면 다음 세 이야기]
    B --> C{각 발언에서 단서를 찾았는가?}
    C -- 아니요 --> B
    C -- 예 --> D[요구와 근거를 인물에게 확인]
    D --> E[팽크허스트: 소개 다음 자료 하나씩 읽고 단서 찾기]
    E --> F[요구·활동·영향 연결]
    F --> G[두 시민: 배경과 발언 다음 선거 참여 범위 비교]
    G --> H[실제 헌법 제1조·제22조의 단서 확인]
    H --> I[러시아 농민: 별도 게임의 토지 요구 회상]
    I --> J[공장 노동자: 경제 운영의 변화 요구]
    J --> K[사회주의의 뜻과 러시아 밖으로의 영향]
    K --> L[젊은 노동자: 두 제안을 담은 변화안]
    L --> M[완성 지도와 핵심 발견]
    M --> N[수업 토론]
```

7명의 목소리를 6개 장면에 담습니다. 첫 여성 노동자는 세 이야기에서 직접 단서를 고른 뒤 정리 버튼을 누릅니다. 팽크허스트는 주요 자료 활동으로 충분히 다루고, 두 시민은 한 장면으로 묶습니다. 이후에는 회상·경제적 요구·변화안 구성으로 활동이 달라집니다. 본편 약 17분에 다시 읽기와 수정 여유를 더해 20분 이내로 설계합니다.

## 2. 7명의 목소리가 만드는 변화 지도

```mermaid
flowchart LR
    A[1 여성 노동자: 선택한 요구와 근거] --> A1[여성 참정권]
    A1 --> P[정치 참여 확대]
    A --> A2[일자리 유지 또는 생활 지원]
    A2 --> Q0[경제적 삶의 개선]
    B[2 팽크허스트: 여성 참정권 운동] --> P
    C[3 평범한 시민: 보통 선거] --> P
    D[4 독일 시민: 공화정 확대] --> P
    E[6 공장 노동자: 생활·경제 운영의 변화] --> Q[경제적 평등 요구]
    F[5 러시아 농민 회상: 토지 문제] --> Q
    G[7 젊은 노동자: 투표권과 생활 개선] --> P
    G --> Q
    P --> R[민주주의의 확산]
    Q -->|공장 노동자 장면에서 개념 연결| S[사회주의의 확산]
    R --> T[정치적 권리와 더 나은 경제적 삶을 함께 요구할 수 있다]
    S --> T
```

첫 정치 참여 카드를 얻으면 ‘민주주의의 확산’이 공개되고, 공장 노동자 장면에서 사회주의의 뜻과 영향을 살펴본 뒤 ‘사회주의의 확산’이 공개됩니다. 마지막 인물의 카드는 양쪽에 연결되지만 수집한 인물 수는 한 명으로 계산합니다. 경제적 요구를 했다는 사실만으로 모든 인물이 사회주의자였다고 단정하지 않습니다.

## 3. 한 장면은 이렇게 나뉩니다

```mermaid
flowchart LR
    A[만나기 전: 전체 그림과 짧은 배경] -->|이야기 들으러 가기| B[현재 인물: 그림과 이름, 읽기 목표, 짧은 발언]
    B --> C[말에서 한 구절 선택해 조사 노트에 남기기]
    C --> D{모든 이야기의 단서를 찾았나요?}
    D -->|아직| B
    D -->|생각 정리하기| E[한 화면에 하나씩 요구와 근거 선택]
    E -->|인물에게 확인하기| F[반응과 기록 카드]
    F -->|다음 목소리 듣기| A
    F -. 변화 지도 .-> G[정치 참여와 경제적 삶의 두 영역]
```

배경·대화·선택·결과를 한 화면에 쌓지 않습니다. 그림은 현재 말하는 인물과 함께 표시하며 두 시민의 이야기를 고르면 이름·그림·발언이 함께 바뀝니다. PC의 옆 영역에는 짧은 조사 노트, 모바일에는 접을 수 있는 노트를 표시합니다. 변화 지도는 두 환경 모두 버튼으로 엽니다.

두 시민에서는 제도·이유를 비교한 다음 실제 헌법을 확인하는 화면이 추가됩니다. 제1조의 권력 주체와 제22조의 선거 참여자를 직접 찾아야 두 목소리가 기록됩니다.

## 4. 기능 구성

```mermaid
flowchart TD
    A[역사 학습 웹앱] --> B[이야기 탐색]
    A --> C[선택과 학습 피드백]
    A --> D[변화 지도]
    A --> E[학습 정리]
    A --> F[진행 관리]
    B --> B1[질문 선택과 단서 수집]
    C --> C1[요구와 근거 연결·제도 비교·정책 제안]
    C --> C2[인물의 인정·추가 설명을 듣고 생각 보완]
    C --> C3[최종 변화안과 개념 연결]
    D --> D1[요구 카드 수집]
    D --> D2[카드별 발언 다시 보기]
    E --> E1[두 요구의 동시 가능성 발견]
    E --> E2[엔딩과 교사 토론 질문]
    F --> F1[같은 브라우저에서 이어하기]
    F --> F2[확인 후 다시하기]
```

회원가입이나 성적표 없이 수업에서 바로 시작하는 구성이며, 교사는 마지막 질문을 활용해 학생의 이해를 확인합니다.

## 5. 마지막 변화안을 만드는 방식

```mermaid
flowchart LR
    A[젊은 노동자 인터뷰] --> B[투표할 권리를 원한다는 발언]
    A --> C[너무 가난하게 살지 않기를 바라는 발언]
    B --> D[정치적 요구와 근거 연결]
    C --> E[경제적 요구와 근거 연결]
    D --> F[정치 참여 확대 제안]
    E --> G[노동자 생활 개선 제안]
    F --> H[두 제안을 담은 변화안]
    G --> H
    H --> I[두 요구를 함께 할 수 있다는 발견]
```

한쪽만 제안하면 인물이 아직 다뤄지지 않은 요구를 이야기합니다. 두 요구와 각각의 근거·제안이 연결되면 완료됩니다. 하나의 정해진 정책 조합만 강요하지 않고, 근거에 맞는 타당한 조합을 허용합니다.

진행 기록에는 들은 이야기, 직접 고른 단서, 현재 화면과 선택 단계, 선택 중인 카드와 조사 완료 상태가 포함됩니다. 같은 브라우저에서는 새로고침 후 이어갈 수 있고, 저장이 차단되면 현재 탭에서 계속할 수 있습니다.

## 6. 엔딩에서 정리할 역사 흐름

```mermaid
flowchart TD
    A[제1차 세계 대전] --> B[전쟁 피해·물가 상승·식량 부족·사회 변화]
    B --> C[예전 세상으로 그대로 돌아갈 수 없다]
    C --> D[나도 정치에 참여하고 싶다]
    C --> E[더 평등하게 살고 싶다]
    D --> F[여성 참정권·보통 선거·공화정 확대]
    E --> G[노동자 생활·토지 문제]
    H[1917년 러시아 혁명: 선행 사건] --> I[사회주의 확산의 배경]
    F --> J[민주주의의 확산]
    G --> I
    J --> K[두 요구는 함께 존재할 수 있다]
    I --> K
    K --> L[토론: 노동자라면 반드시 하나만 선택해야 했을까?]
```

공화정이 언제나 민주주의를 보장하는 것은 아니며, 나라별 변화의 시기와 범위도 다릅니다. 게임에서는 대표적인 사례를 통해 두 학습 축을 이해하게 합니다.

## 7. 팽크허스트를 다루는 방식

```mermaid
flowchart LR
    A[누구인가: 영국 여성 참정권 운동과 WSPU] --> B[편지: 어떤 법을 바꾸려 했나요?]
    B --> C[운동: 동료들과 무엇을 했나요?]
    C --> D[1918년 자료: 어떤 제한이 남았나요?]
    D --> E[훗날 1928년: 남녀가 같은 연령 조건]
    E --> F[권리·행동·사회 변화를 하나씩 연결]
    F --> G[여러 운동가의 노력과 전쟁 중 여성의 기여]
```

동아 역사1 교과서 187쪽의 자료를 바탕으로 누구인지·무엇을 했는지·어떤 변화에 기여했는지 살펴봅니다. 여성 참정권 확대를 한 사람만의 성과로 단정하지 않습니다.

## 8. 두 게임을 연결하는 방식

```mermaid
flowchart LR
    subgraph Previous[별도 러시아 혁명 게임]
        A[전쟁·생활·토지 요구] --> B[혁명 과정과 소비에트 정부]
        B --> C[토지와 산업의 국유화]
    end
    subgraph Current[1919년 목소리 조사 게임]
        D[농민의 토지 요구 회상] --> E[유럽 노동자의 경제적 요구]
        E --> F[사회주의의 뜻과 경제 운영 변화]
        F --> G[러시아 혁명이 다른 나라의 운동에도 미친 영향]
        G --> H[정치적 권리와 경제적 삶을 함께 요구]
    end
    A -. 이전 경험 연결 .-> D
    C -. 구체적인 개혁 사례 .-> F
```

이전 게임의 저장 기록을 요구하지 않으며 러시아 혁명의 사건을 다시 플레이하지 않습니다. 사회주의는 혁명 이전부터 있었고, 생활 개선 요구를 한 사람이 모두 사회주의자는 아니라는 점을 구분합니다.

## 9. 첫 여성 노동자의 선택 분기

```mermaid
flowchart TD
    A[삽화와 시대 배경] --> B[세 질문을 듣고 각각의 단서 고르기]
    B --> C[주목한 요구와 발언 근거 연결]
    C --> D{요구와 근거가 연결되는가?}
    D -- 아니요 --> E[선택을 유지하고 발언 다시 살펴보기]
    E --> C
    D -- 예 --> F{학생이 고른 요구}
    F --> G[일자리 유지: 경제적 삶의 개선 카드]
    F --> H[생활 지원: 경제적 삶의 개선 카드]
    F --> I[정치 참여: 여성 참정권과 민주주의 연결]
    G --> J[선택한 카드 한 장을 지도에 기록]
    H --> J
    I --> J
    J --> K[결과 확인 또는 다른 요구 살펴보기]
    K -- 다른 요구 --> C
```

경제적 요구를 곧바로 사회주의로 분류하지 않습니다. 다른 요구를 살펴보는 동안 기존 카드는 보존합니다. 새 제출이 확인되면 첫 인물의 카드를 교체하고, 이후 목소리로 이어갈 수 있습니다.

## 10. 효과와 진행 기록

```mermaid
flowchart TD
    A[그림과 새 화자 등장] --> B[발언의 단서 선택]
    B --> C[발언 밑줄과 조사 노트 효과]
    C --> D[학생의 제안 확인]
    D --> E[목소리 기록 도장과 카드 수집]
    E --> F[마지막 정치·경제 제안 연결]
    S[기본 꺼짐 효과음] -. 사용자가 켜면 .-> A
    M[기기의 동작 줄이기] -. 등장·수집 애니메이션 생략 .-> F
```

점수·감점·강제 대기는 없습니다. 예전 v1/v2/v3 기록은 새 흐름(v4)으로 옮기며 모았던 목소리와 제안은 보존합니다.
